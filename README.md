# Matek 100

Testreszabható matematika feladatgenerátor kisiskolásoknak — statikus weboldal, GitHub Pages-re.

## Funkciók

- 100 feladat (alap), 4 oszlop × 25 sor
- Művelet választható: összeadás, kivonás, szorzás, osztás
- Számhatárok műveletenként, külön operandum- és eredménytartományra
- Negatív eredmény engedélyezése (kivonásnál)
- Osztásnál mindig egész eredmény (osztandó = osztó × hányados)
- Rendezés: véletlen (kiegyensúlyozott) vagy oszloponként azonos típus
- Élő előnézet, közvetlenül szerkeszthető feladatok
- Nyomtatható / PDF-ben menthető (böngésző nyomtatás, A4)
- Automatikus megoldáskulcs (kikapcsolható)
- Szerkeszthető cím és dátum, névsor

## Használat

Beállítások a bal oldalon, élő előnézet jobb oldalt. „Újragenerálás" új feladatsort ad,
„Nyomtatás / PDF" a böngésző nyomtatási párbeszédét nyitja (mentés PDF-ként).

## Technológia

Vanilla HTML/CSS/JS (ES modules), build nélkül. Fájlok: `index.html`, `style.css`, `js/`.

## Közzététel

GitHub Pages: a repó Settings → Pages → Branch: `main`, folder: `/ (root)`.
